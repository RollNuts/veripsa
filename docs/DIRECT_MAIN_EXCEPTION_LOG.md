# Direct-main exception log

The public repository uses pull requests for changes to `main`. If an emergency change
ever bypasses that path, record only content-free facts here: date, affected paths,
reason, risk, verification, and corrective action. Never record credentials, provider
resource identifiers, incident selectors, customer data, payloads, or private repository
names.

No direct-main exceptions have occurred in this public repository.

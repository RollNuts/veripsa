# Changelog

## Unreleased — reproducible local evidence and project navigation

### Added

- A local structural-overlap demo using Git, Python 3.12, the existing Core extractor, and the offline evaluator's coarse adjacency helper. Synthetic cases compare individual execution, actual clean Git merges, observed relationships, and combined execution.
- Compatible related changes, unrelated changes, and a missed dynamic lookup alongside the failing function-contract example, so a relationship is not presented as a bug verdict and absence is not presented as Clear.
- Small API-route and configuration-key probes using existing parsers.
- An English diagram, a Japanese 30-second / 3-minute / 10-minute guide, and author links to RollNuts.
- Draft repository descriptions, three X drafts, and a background article grounded in the reproducible cases. These materials have not been posted externally.

### Changed

- README entry points now lead to the local demo, then the existing pinned Flask evaluation, engineering choices, and the separate read-only MCP experiment.
- Architecture and product-fact documentation clarify the current maintenance goal: useful engineering, reproducible evidence, and understandable public work. Revenue, sales, new billing flows, and a hosted-service restart are outside this work.
- Roadmap wording distinguishes implemented source from a currently available GitHub App.

### Availability and verification scope

The hosted GitHub App remains suspended since 2026-08-18. The local demo does not execute the PostgreSQL PR-decision pipeline or establish a live hosted check. Its expected output includes both a related change that works and an unobserved dynamic relationship that fails. The separate MCP adapter queries a saved snapshot; its optional Codex path consumes the user's model allowance and is not needed for the free local demo.

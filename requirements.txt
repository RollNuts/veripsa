# Every dependency carries an explicit UPPER bound (not just a floor): a build is then reproducible and a
# surprise/compromised MAJOR can't silently ship in a rebuild. These ceilings MUST stay in sync with
# github-app/Dockerfile (the prod image installs the same bounds). Bumping a ceiling is a reviewed change.
#
# This file installs the FULL runtime set with `pip install --no-deps -r requirements.txt` — there are NO
# environment markers (`; extra == "..."`) on any line. A marker like `extra == "multilang"` evaluates True
# ONLY when pip installs a package that DECLARES that extra (e.g. `pip install foo[multilang]`); for a bare
# install of this manifest the `extra` variable is undefined, so EVERY marked line is SKIPPED. With
# no pyproject.toml/setup.py defining those extras (there is none), the markers were unsatisfiable and the
# documented venv/image install (RUNBOOK §B) installed psycopg2 ONLY — the App then ImportError'd on the first
# graph ingest (`from tree_sitter import Parser`) and on App-JWT signing (`import jwt`). The Dockerfile already
# installs all of these unconditionally, so the markers added a broken-runtime trap with no benefit. They are
# gone: the explicit install now yields the exact set the prod image installs (asserted by the supply-chain gate).
psycopg2-binary>=2.9,<2.10
# Multi-language code graph: Python is parsed with the stdlib `ast` (no dep); other languages are parsed
# with tree-sitter. Each grammar loads independently; any absent/version-incompatible one is skipped (the
# extractor degrades to fewer languages, never fatal — and unsupported source still gets direct-collision
# protection). Add a language = one grammar here + one entry in code_graph_extract._GENERIC_SPEC.
#
# tree-sitter CORE: pinned exactly to 0.23.2 ON PURPOSE — it is the LOAD-BEARING pin of the ABI scheme. The
# 0.23.x runtime speaks language-ABI v14 (accepts grammars v13–14); 0.24+ speaks ABI v15 and raises the minimum,
# which would silently DROP the deliberately-old grammar pins below (rust/c/cpp/swift/kotlin are held at v14
# versions). Without this exact pin a fresh install could resolve the core to a future major and shrink
# language coverage with no error. The resilient loader (_cg_languages._ts_languages) prevents a CRASH on a
# mismatch; this pin prevents a SILENT coverage loss. Bump core + grammar pins together as one reviewed step.
# Install this manifest with `pip install --no-deps -r requirements.txt`: every transitive runtime dependency
# is listed below, and bypassing package metadata is required because language-pack 0.9.1 over-constrains the
# external C# wheel even though Veripsa uses its bundled Dart grammar. The supply-chain gate locks this command.
tree-sitter==0.23.2
tree-sitter-javascript>=0.23,<0.24
tree-sitter-typescript>=0.23,<0.24
tree-sitter-go>=0.23,<0.24
tree-sitter-java>=0.23,<0.24
tree-sitter-ruby>=0.23,<0.24
# php / c# / html field-specs are DONE (grammar-verified: php class/interface/trait/enum + namespace_use;
# c# class/interface/struct/record + using; html script/link refs). Roadmap remaining: rust field-specs.
# `cryptography` (single entry below, with pyjwt) is used by BOTH the live App-JWT RS256 signing (server.py)
# and the optional signed audit export (export_audit.py — Ed25519; if cryptography is absent it falls back to
# RSA via the `openssl` CLI, then to sha256-only tamper-detection). One pin serves both; same floor/ceiling.
tree-sitter-php>=0.23,<0.24
